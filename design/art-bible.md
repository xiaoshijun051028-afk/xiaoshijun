## 1. 世界观与情绪基调（Visual Tone & Mood）

《星陨之境》是一场在坠落的星河中挥刃的飘渺史诗。远古星天碎裂成浮空群岛，被「共鸣」之力悬于云海之上；旅人持星刃穿行其间，斩破由混沌侵蚀而成的机械造物，追寻失落的共鸣之源。整体气质定位为 **「壮美、空灵、带一丝苍凉的希望感」**——以明快饱和的色板与强体积光塑造令人屏息的浮空奇景，用东方奇幻的山川灵气叠合日式精美的器物典雅，使玩家在爽快的动作中始终被「美」与「孤独壮游」双重包裹。战斗要「爽」，世界要「美」，二者通过统一的星辉青（共鸣）与暖金（希望）基调收束为同一视觉语言。

## 3. 光影语言（Lighting & Shadow — Godot 4）

### 3.1 总体策略
- **主光（Key）**：单一 `DirectionalLight3D` 扮演「星核之日」，暖金偏白、角度偏低（拂晓/黄昏感），制造长投影与体积感。
- **补光（Fill）**：苍穹蓝环境光 + 暮紫染调，压暗部但保留色彩，避免死黑。
- **GI**：户外大世界用 **SDFGI**（Godot 4 内置，实时全局光照，适合浮岛弹跳光）；封闭遗迹/洞窟可用 `VoxelGI` 或叠加点光。所有参与 GI 的网格材质设 `gi_mode = Static/Dynamic`。
- **体积光**：`WorldEnvironment` 开启 **VolumetricFog** + 指数 `Fog`，制造强体积光束（god rays）与云海层雾；用高度雾（height fog）托住岛屿下缘的云海。

### 3.2 天空与昼夜
- 不使用写实 PhysicalSky，改用 **自定义 Sky Shader**：渐变天幕 + 程序化「星陨流光」（缓慢下落的星痕）+ 极光带（aurora band），强化"星天碎裂"世界观。
- **时间系统**：不做完整昼夜循环，改用 **「共鸣潮汐」**——缓慢的色温/天幕染色循环（暖金 ↔ 苍穹 ↔ 暮紫），既保氛围又省性能、利于风格统一。

### 3.3 后处理
- `WorldEnvironment` 内 `Exposure` 轻微提亮高光、`Glow`（Bloom）强化星辉青/暖金的能量感（阈值偏高，避免整体发灰）。
- 自定义全屏特效（故障、径向模糊、色散）走 Godot 4.3+ 的 **CompositorEffect**，集中管理、可控强度。

## 4. 材质与表面（Materials & Surfaces — stylized PBR）

### 4.1 粗糙度 / 金属度取向
stylized ≠ 物理随机；以「可读性 + 精美边缘」为先，控制参数区间：

| 表面类别 | Roughness | Metalness | 备注 |
|---|---|---|---|
| 浮空岩 / 建筑石 | 0.70–0.90 | 0.00 | Albedo 渐变分带（stylized banding），非噪点 |
| 共鸣金属（敌/机关） | 0.20–0.40 | 0.60–0.90 | 镜面克制，配自发光描边 |
| 植被 / 有机 | 0.50–0.80 | 0.00 | Albedo 带微次表面暖调 |
| 星木 / 结晶 | 0.30–0.60 | 0.00–0.20 | 半透/晶体用透射或 emission |

### 4.2 材质库方向（命名建议，待资产清单落地）
- **AuroraStone（星纹岩）**：分带渐变岩 + 内嵌发光脉络（emissive vein）。
- **ResonanceMetal（共鸣金属）**：拉丝金属 + 星辉青自发光镶边，用于机关与部分敌人。
- **StarWood（星木）**：木纹中藏微弱星斑，建筑主材。
- **HazeGlass（雾晶）**：半透晶体，折射低、自发光点缀，用于共鸣节点。

### 4.3 美术技法纪律
- 贴图打包用 **ORM**（Occlusion/Roughness/Metalness 合并）省采样。
- 全项目统一加一层 **Fresnel Rim**（边缘高光）`ShaderMaterial`，给物体"精美描边"—— hero 与重要道具用强 rim，环境弱 rim。
- 避免高频噪点法线；stylized 用「大块明暗 + 干净高光」而非写实脏旧。

## 5. 角色设计语言（Character Design Language）

### 5.1 主角 · 星刃旅人（Starblade Wanderer）
- **剪影**：纤长、飘逸——标志性「星带」长披帛随动作拖曳，在天空背景下形成极高辨识度的流动轮廓；非对称（单肩甲 + 短披风），显敏捷不显笨重。
- **配色**：深岩灰底（`#2A3140` 系）让世界色板跳出来，星辉青 + 暖金做点缀；发色/私有强调用暖金。
- **辨识锚点**：星刃恒发星辉青光；披帛拖尾为身份符号；human scale、优雅、轻盈。
- **原则**：有机曲线、布料流动、克制装甲——与敌人的硬机械形成天然对比。

### 5.2 敌人 · 混沌机械造物（Chaos Mechanical Constructs）
- **剪影**：棱角几何、刻意**打破对称**（错位关节、尖刺、 dissonance 形态），比旅人高大但读作"构造物"而非生物。
- **配色**：枪铁灰底（`#3A3F4B`）+ 混沌品红（`#A62C6B`）脉冲能量侵蚀。
- **辨识锚点**：不规则几何 + 品红辉光 + 抖动/故障（glitch）动效；威胁感来自"非自然的不稳定"。
- **原则**：「被造而非被生」——板甲、活塞、碎裂星科技；平滑有机的 hero vs 硬朗机械的 enemy，一眼可辨。

### 5.3 辨识度总原则
- **Hero = 曲线 + 青/金 + 流动布料**；**Enemy = 硬角 + 品红 + 僵硬/故障**。快节奏战斗中靠剪影与冷暖即可 0.2 秒内分辨敌我，不依赖细节贴图。

## 6. 环境 / 场景语言（Environment / Scene Language）

### 6.1 浮空群岛构成
- 岛屿为**倒泪滴岩体**：顶部平整可居，底部 crystalline 尖锥「根」垂入虚空/云海——视觉上"被共鸣吊起"。
- **标尺（Human Scale）**：小岛（一树一 shrine）→ 中岛（村落遗迹）→ 大岛（破碎城郭）；玩家通过**跃**（jump）、**荡**（grapple/swing）、**共鸣桥**（resonance bridge）穿越。
- **垂直叙事**：世界核心是"高度"——俯瞰云海、仰望星陨；关卡动线鼓励向上探索。

### 6.2 植被与生态
- stylized 略夸张叶形；**星花**（微弱自发光）、漂浮花粉光点（motes）；东方奇幻 flora（竹状苇、金瓣落英替代樱）。克制密度，保通透感。

### 6.3 建筑风格
- **东方奇幻 × 日式精美**：浮空鸟居式门、曲檐塔fragment、木构神社；赤陶 + 深木 + 星纹岩；遗迹被共鸣藤蔓/光脉温柔收复，而非破败狰狞。

### 6.4 云海与远景
- 体积雾托底的云海，远景更大岛屿剪影 + 极光带，营造"无尽浮空界"的纵深。

## 7. UI 视觉基调（UI Visual Tone）

### 7.1 方向（与 3D 世界同语言）
- **框体语言**：纤细星辉青/暖金线条 + 圆角面板，图形母题为"共鸣符文/星纹"，非重科幻、偏"典雅符牌"。
- **字体**：标题用书法感衬线（东方奇幻气）；正文用干净无衬线（可读性优先）。
- **色彩**：复用语义色板——玩家青、暖金点缀、品红=敌/警告；中性底 `#1A2233` 半透面板。
- **Diegetic 倾向**：生命/共鸣表现为「星核球」或刃能环而非裸血条，但仍保高可读性。
- **菜单**：世界视差浮岛背景 + 柔体积光 + 世界模糊（blur）后置，沉浸不抢戏。
- **世界空间 UI**：伤害数字、敌人标记沿用同一符文语言，保持统一。

## 8. VFX 与着色器方向（VFX & Shader — Godot 4 可行性）

| 效果 | 方向描述 | Godot 4 实现路径 | 可行性 |
|---|---|---|---|
| 星刃拖尾 | 加色混合的青色渐变缎带 + fresnel + 星痕噪动 | `TrailMesh`/自定义 ribbon + `ShaderMaterial`（Additive） | ✅ 易 |
| 共鸣光效 | 自发光脉冲 + 扩散环 shader + 光点粒子爆发 | `GPUParticles3D` + ring/sine shader | ✅ 易 |
| 混沌侵蚀 | UV 位移 + 色散 + 扫描线噪动的故障 shader；品红脉络程序化 | `ShaderMaterial` + `CompositorEffect` | ✅ 中 |
| 体积光束 | 强 god rays / 光轴 | `VolumetricFog` + `DirectionalLight3D` | ✅ 内置 |
| 闪避 i-frame | 时间切片/运动模糊 + 瞬时去饱和闪 | `CompositorEffect`（custom post） | ✅ 中 |
| 跃/荡 速度线 | 屏幕空间径向streaks | 自定义后处理 / 粒子 | ✅ 中 |
| 天空星陨 | 程序化下落星痕 + 极光 | `Sky` 自定义 shader | ✅ 易 |

### 8.1 落地纪律
- 全屏自定义特效统一走 **CompositorEffect**（4.3+），设可调节强度（含可访问性降档）。
- 粒子用 `GPUParticles3D`，封顶数量；拖尾做 LOD，远处降帧率/降密度。
- 慎用 SSR（屏幕空间反射）——PC 可行但记账；优先 SDFGI + 受限反射探针。

## 9. 可访问性初步（Accessibility Baseline）

### 9.1 色盲友好
- **核心风险**：玩家青（`#5FD2C8`）vs 敌人品红（`#A62C6B`）对多数 CVD 可辨，但**不仅靠色相**——叠加形状/明度编码（曲线 vs 硬角、图标差异）。
- **禁红绿单编码**：可交互用暖金 + 图标，不靠红绿区分。
- **高对比/色盲模式**：将混沌品红切换为更高明度差的替代 + 脉动描边 + 纹理图案，确保 Protan/Deutan/Tritan 均可辨。

### 9.2 对比度与可读性
- UI 文本对比度 ≥ **4.5:1**（WCAG AA），标题 ≥ 3:1；文本下垫半透深空底 `#1A2233`。
- **字号基线**：HUD ≥ 18px 当量，菜单 ≥ 20px；支持放大至 **150%**。
- 字幕默认开启（有台词处），可调大小/背景；提供**易读字体**选项（低 dyslexia 风险）。

### 9.3 动效与生理
- 提供**镜头抖动 / 暗角减弱**开关；混沌故障（高频闪烁）特效设**强度滑块**，降低光敏/眩晕风险。
- 输入重映射与按键图标清晰化属 UX 范畴（交文策渊落地 UX 规格），本圣经要求其引用可访问性分级。

### 9.4 分级建议（Solo 基线）
- 建议以 **Standard** 级为上线基线（语义色 + 字幕 + 文本缩放 + 色盲/高对比模式 + 抖动减弱），向 **Comprehensive** 演进（完整重映射、字幕全量、动态难度提示）。UX 规格须显式引用此分级。
