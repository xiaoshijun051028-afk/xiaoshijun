## 0. 总原则（不可协商底线）
- **语义色纪律是设计层强制项，不随分级降级**：`THREAT=#A62C6B` 仅敌/混沌专属；`RESONANCE_GLOW=#9FF7E8`（青白）与威胁品红严格区分；FRIENDLY = FRIENDLY_TEAL/PLAYER_ALLY_MAIN `#5FD2C8` + FRIENDLY_AMBER `#F2C15E` + FRIENDLY_CORAL `#FF8A65`（来源 `design/color-tokens.md` v1.0（唯一权威））。色盲模式可替换显示色，但**不得**让威胁品红外溢到中立/友好用途。
- **美术圣经 §9 的"初步建议"在本文件升级为可执行分级矩阵**；v1 推荐 **Standard** 级（与 §9 建议一致）。
- 难度提示/动态难度直接呼应 **CONCERN-1**（Hard telegraph 下限 0.4s 对低技能玩家可能跌破心流带），是心流守护的可访问性表达，非"降低挑战"。

## 1. 三级定义（Tier Definitions）

### Basic — 出厂即保底线（Always-On Floor）
不依赖任何开关、默认即满足的最低保障。覆盖"游戏可玩且不被生理条件直接劝退"的核心项：语义色纪律、威胁形状/明度编码、字幕默认开、字号硬底线、双输入。目标人群：默认体验下绝大多数玩家；为更低能力者提供"不崩坏"的基础。

### Standard — 可调个体差异（v1 推荐基线）
在 Basic 之上，提供**用户可调选项**以应对个体差异：完整三型色盲模式、高对比模式、字号放大、字幕细调、镜头抖动/暗角/故障闪烁强度滑块、输入重映射+清晰图标、难度提示/辅助预设。成本集中在"选项菜单 + Shader/参数开关"，Godot 4 落地可行。目标人群：有色觉/视觉/运动/输入差异的玩家可自助适配。

### Comprehensive — 深度自适应（v1 演进路径，非必须）
Standard 全量 + 更深自适应：自适应动态难度（实时守心流带，直接消 CONCERN-1）、全量字幕（含环境/战斗语音）、自定义调色板/图案纹理编码、独立分级缩放、运动模糊/FOV 可调、音频可视化。多对应概念 MoSCoW 的 Should/Could，不作为 v1 必须。

## 2. 特性矩阵（Feature × Tier）

**图例**：✅ 全覆盖 ｜ 🟡 部分/条件覆盖 ｜ ⬜ 不覆盖
**单元格** = 该级对此特性的支持描述。

| # | 特性 | Basic | Standard | Comprehensive |
|---|---|---|---|---|
| F1 | **色盲模式**（Protan/Deutan/Tritan；形状/明度编码；威胁品红仅敌/混沌） | 🟡 形状/明度兜底：威胁附**菱形+脉冲**（S6 §6 强制），不单靠色相；**不**做色相替换 | ✅ 三型颜色替换（Protan/Deutan/Tritan 调色板）+ 图标叠加；替换后仍守"威胁品红仅敌/混沌"纪律；非敌危险 `DAMAGE_WARN=#E5484D`（低血/受击）在 CVD 模式转鲜橙 + ⚠ 图标，与治疗绿保持红绿区分（详见 `design/color-tokens.md` §2） | ✅ 标准全部 + 用户**自定义调色板/图案纹理**编码（除色相外叠纹理），全 HUD/世界空间一致 |
| F2 | **高对比 / 高对比模式** | 🟡 默认 UI 文本对比度 ≥ **4.5:1**（WCAG AA，美术圣经 §9）；半透深空底 `UI_BG=#1A2233` 托字 | ✅ 一键高对比模式：提对比/降眩光/强化描边（UI + 关键世界元素） | ✅ 标准全部 + 场景级对比增强层 / 动态对比适应 |
| F3 | **文本字号基线 + 放大**（HUD≥18 / 菜单≥20，放大 150%） | ✅ 硬底线 HUD≥18 / 菜单≥20（不可低于）；九宫格锚定适配 720p–4K（S6 §6） | ✅ 全局字号放大滑块至 **150%**（HUD/菜单/字幕统一） | ✅ 标准全部 + 分级独立缩放（HUD/菜单/字幕各自）+ 超放大 200%+ |
| F4 | **字幕**（默认开、大小/背景可调、易读字体） | ✅ 默认开（残响叙事文本 fallback，S7 §6 语言缺失回退文本）；基础易读字体 | ✅ 大小/背景可调 + 易读字体选项（低 dyslexia 风险）；残响可跳过（S7 8–20s 可跳过） | ✅ 标准全部 + **全量字幕**（环境音/战斗语音/残响全收录）+ 说话者标识 + 位置可调 |
| F5 | **镜头抖动 / 暗角 / 故障闪烁 强度滑块**（光敏/眩晕） | 🟡 基线控制：混沌故障特效默认有上限（美术圣经 §9 纪律），无独立滑块 | ✅ 独立强度滑块（抖动 / 暗角 vignette / 故障闪烁，可分别调或总开关），可降至 0 | ✅ 标准全部 + 运动模糊/FOV/屏幕位移可调 + 光敏安全模式（全局去高频闪烁） |
| F6 | **输入重映射 + 按键图标清晰** | ✅ 键鼠+手柄双输入、最近设备优先（S6 §6）；默认图标清晰 | ✅ **输入重映射**（自定义键位）+ 清晰按键图标（符号化、与 6 动词一致） | ✅ 标准全部 + 多预设/完整自由重映射 + 单手/辅助控制器支持 |
| F7 | **难度提示 / 动态难度**（呼应心流，关联 CONCERN-1 Hard） | 🟡 静态预警：S4 招式 telegraph 本就利于读招；无动态调节 | ✅ **难度提示/辅助预设**（如辅助格挡窗口放宽、telegraph 延长辅助模式，直接守 CONCERN-1 的 0.4s 心流带）；难度预设 Normal/Hard 等 | ✅ 标准全部 + **自适应动态难度**（实时按表现微调 telegraph 下限/窗口，守心流带，消 CONCERN-1） |
| F8 | **语义色复用纪律**（THREAT 仅敌/混沌等） | ✅ **强制**（design/color-tokens.md v1.0 唯一权威；THREAT/RESONANCE_GLOW/FRIENDLY 全量遵守） | ✅ 标准全部 + 可访问性模式下语义色不变/强化（色盲替换仍守纪律） | ✅ 标准全部 + 审计确保所有新增资产符合语义色纪律 |

> **跨级铁律**：F1 与 F8 在任何级均不得跌破"威胁品红仅敌/混沌"——这是单一真相源（`design/color-tokens.md` v1.0）的硬约束，色盲模式（F1）的显示色替换也须在其框架内。

## 3. v1 推荐与演进路径

### 3.1 v1 推荐：Standard 级（理由）
- **Solo 评审、资源集中**：Standard 覆盖绝大多数玩家生理差异（三型色盲、字号、字幕、抖动/眩晕、输入、难度辅助），成本集中在"选项菜单 + Shader/参数开关"，Godot 4 落地可行（见 §5）。
- **Baseline 不足、Comprehensive 超纲**：Basic 仅"不崩坏"、缺个体调节；Comprehensive 的"自适应动态难度""全量字幕/音频可视化"超出 v1 Must——概念 MoSCoW 中动态难度/NG+ 属 Should/Could，音频可视化未列。故 Standard 为合理上限。
- **与美术圣经 §9 一致**：§9 即建议 Standard 为 Solo 基线，本文件将其落地为可勾选矩阵。

### 3.2 Comprehensive 演进路径（非 v1 必须，标注 MoSCoW 归属）
| 升级项 | 对应 Tier 特性 | 概念 MoSCoW 归属 |
|---|---|---|
| 自适应动态难度（实时守心流带） | F7 | Should（难度选项/NG+ 同族） |
| 全量字幕（环境/战斗语音） | F4 | Should（残响叙事同族） |
| 自定义调色板 / 图案纹理编码 | F1 | Could（表达/定制） |
| 独立分级缩放 + 超放大 | F3 | Could |
| 运动模糊/FOV/光敏安全模式 | F5 | Could |
| 音频可视化（视觉化音效/方向） | 新增 | 未列 / Could |
| 单手/辅助控制器支持 | F6 | Could |

## 5. Godot 4 落地指引（可执行性）
- **F1 色盲**：集中管理语义色为 `Theme`/材质参数（便于一键替换）；后处理用 **CompositorEffect** 做 Protan/Deutan/Tritan 色相旋转；形状编码=UI 图标 + 世界空间菱形 sprite（威胁 telegraph）。
- **F2/F3 高对比/字号**：`Control.theme_override_*` + 全局 `Theme`；UI 缩放用 `get_tree().root.content_scale_factor` 或自定义缩放因子，九宫格锚定。
- **F5 抖动/故障滑块**：混沌故障 `ShaderMaterial` 暴露 `u_glitch_strength`；镜头抖动= `Camera3D` 位移幅度参数化；暗角=后处理 uniform；均接设置菜单滑块。
- **F6 重映射**：Godot 4 `InputMap` 运行时重映射；图标用统一 6 动词符号集。
- **F4 字幕**：`RichTextLabel`/`Label` + 可调字号/背景 `Panel`。
- **F7 难度**：逻辑层参数化（S4 telegraph 窗口），非渲染，Standard 用预设、Comprehensive 用实时反馈闭环。
- **性能**：色盲/高对比为参数切换零持续成本；故障/抖动滑块仅在开启时增加 Shader uniform 开销，PC·Steam 充裕。
