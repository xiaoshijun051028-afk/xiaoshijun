# GDD · 移动与垂直穿越 (Movement & Vertical Traversal)
> 系统编号 S2 ｜ 版本 v0.2 ｜ 依赖 S5(锚点) ｜ 上游 概念文档 v0.2

## ① 概述与目标
通过 闪 / 荡 / 跃 实现浮空群岛的垂直移动（支柱 P2「垂直即世界」）。轻重力浮空物理 + 锚点系统让玩家以空中为主场，涌现"绕怪空中路线"。与战斗共享取消窗口，保持流动。

## ② 核心机制/规则
- 轻重力：重力 ≈ 0.6g（地球 0.6 倍），跳跃/悬停更飘。
- 荡 Grapple：对 ≤15 m 内锚点/可抓敌人发射钩索，拉向目标；空中可连续荡（动量守恒）。
- 跃 Leap：垂直起跳 3–4 m，顶点 0.4s 悬停（可接闪调整）。
- 闪 Dash：水平位移 4–6 m，兼战斗无敌（见 S1）。
- 锚点：世界放置 `grapple_anchor`（S5）；不可抓表面显灰，可抓显 `RESONANCE_GLOW` 描边。
- 取消链：跃 → 闪 → 斩 连续无断裂（查 CANCEL_WINDOW）。

## ③ 状态与数据流
- 状态：grounded(0/1)、airborne(0/1)、grappling(0/1)、velocity(vec3)、anchorTarget(ref)。
- 数据流：输入 → 物理步（轻重力积分）→ 碰撞/锚点检测 → 位移应用 → S6 小地图/高度提示。
- 不持久；位置随神龛存档（S8）。

## ④ 与其他系统接口
- → S5：读取锚点列表；越界触发坠落（→ S8 复活）。
- ↔ S1：闪/跃为共享动词，取消窗口一致。
- → S6：暴露高度/区域名/锚点可用。
- → S8：神龛为安全落点。

## ⑤ 数值/参数初值
- 重力 0.6g（≈ -5.88 m/s²）。
- 移动速度 5–7 m/s（地面），空中 6–8 m/s。
- 荡：绳长 4–15 m，拉速 12–16 m/s，可脱钩。
- 跃：高 3–4 m，悬停 0.4s，cd 0.6s。
- 闪：见 S1（4–6 m，10f iframes）。
- 锚点密度：每 1000 m³ 可见锚点 ≥ 1（满足 P2 ≥0.6 可达比）。

## ⑥ 边界与失败处理
- 锚点失效：脱钩中锚点消失 → 保留当前速度自然滑落，不瞬移。
- 越界坠落：y < 世界下限 → 0.5s 后神龛复活（S8），不掉进度。
- 卡墙：碰撞体粘连检测，0.2s 自动解卡推离。
- 多锚点重叠：优先最近且视线无遮挡。

## ⑦ 可测试性
- [ ] 单岛可达高点数/体积比 ≥ 0.6（关卡编辑器统计）。
- [ ] 存在 ≥1 条纯空中路线绕过地面敌人（手工验证 + 录像）。
- [ ] 跃 → 闪 → 斩 取消延迟 ≤ 8 帧。
- [ ] 越界坠落 100% 触发神龛复活无卡死。
