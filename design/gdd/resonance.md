# GDD · 共鸣能量池 (Resonance Pool)
> 系统编号 S3 ｜ 版本 v0.2 ｜ 根资源（无前置依赖）｜ 上游 概念文档 v0.2

## ① 概述与目标
单一共享能量池，同时驱动解谜闸门（S5）与战斗终结技（S1），互斥消耗——兑现支柱 P4「共鸣统一」与防主导策略。池数值为全局 Single Source of Truth（见 systems-index §2）。

## ② 核心机制/规则
- 池 max 100，初始 50。
- 获取：近战命中 +1/次；完美格 +5；击杀 +15；世界共鸣节点（S5/S7）+10/次；脱战被动 +2/s。
- 消耗：解谜闸门 `GATE_COST=30`；终结技 `FINISHER_COST=40`。
- 互斥：同一池，开门后池低则无法放终结技，反之亦然 → 玩家须权衡（防主导策略）。
- 共鸣动作（resonate verb）：在节点/敌人处引导星刃，触发上述消耗或获取。

## ③ 状态与数据流
- 状态：resonance(0–100)、inCombat(0/1)、lastGainSource(enum)。
- 数据流：事件（命中/格挡/击杀/节点/脱战）→ 增减 → 上限钳制 → 广播给 S1/S5/S6/S7。
- 持久化：随神龛存档（S8）记录当前值。

## ④ 与其他系统接口
- → S1：终结技扣 40；池不足禁用。
- → S5：闸门扣 30；不够不解锁。
- → S7：节点共鸣 +10 并触发叙事。
- → S6：HUD 显示池量与"可终结技/可开门"状态。
- → S8：存档/读档同步。

## ⑤ 数值/参数初值（范围）
- MAX 100，初始 50。
- 增益：命中 +1，完美格 +5，击杀 +15，节点 +10，脱战 +2/s。
- 消耗：闸门 30，终结技 40。
- 调节（Should 技能树）：节点 +15，脱战 +3/s。

## ⑥ 边界与失败处理
- 池溢出：达 100 停止增长，多余增益丢弃（不保留）。
- 双重消耗竞争：同一帧既开门又终结技 → 优先玩家主动输入（终结技），闸门排队。
- 节点重复共鸣：节点有 cd 5s，防刷池。
- 脱战判定：3s 无敌人接触视为脱战开始被动回充。

## ⑦ 可测试性
- [ ] 池上限严格 100，不溢出。
- [ ] 终结技恰好扣 40，闸门恰好扣 30。
- [ ] 池=35 时可开门(30)但不可终结技(40)——互斥验证。
- [ ] 节点 5s cd 内重复触发不二次增益。
