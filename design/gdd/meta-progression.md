# GDD · 元进度系统·神龛 (Meta-Progression: Shrines)
> 系统编号 S8 ｜ 版本 v0.2 ｜ 依赖 S5(神龛位), S1(技能树效果) ｜ 上游 概念文档 v0.2

## ① 概述与目标
神龛为唯一存档/复活点（兑现核心循环"神龛读档→…→神龛存档"）。Should 级共鸣配装技能树在神龛应用，兑现美学 Expression。目标：Meta 进度轻量、无 grind（防经济失衡）。

## ② 核心机制/规则
- 存档：神龛交互 → 写盘（玩家状态/共鸣池/岛屿进度/残响/技能树）。
- 复活：死亡/坠落 → 最近神龛满血复活，保留进度（不掉收集）。
- 技能树（Should）：共鸣配装分支，影响 S1（取消窗口/伤害/完美闪奖励）、S3（增益）、S2（移动）。
- 无货币/经济：技能点来自"发现/里程碑"，非刷怪（防经济失衡）。

## ③ 状态与数据流
- 状态：saveSlot、lastShrine、skillPoints、skillUnlocked[]。
- 数据流：交互神龛 → 序列化 → 写盘；读档 → 反序列化 → 应用至 S1/S2/S3/S5/S7。

## ④ 与其他系统接口
- ← S5：神龛位。
- → S1/S2/S3：技能树效果。
- → S6：技能树 UI。
- → S7：残响存档。

## ⑤ 数值/参数初值
- 神龛每岛 ≥1。
- 复活：满血，保留全部收集与技能。
- 技能点：每里程碑 +1（约每岛 2–3 点），总 ≈ 12–16。
- 技能树分支：3 系（迅捷/共鸣/守护），每系 4–5 节点。
- 取消窗口下限 5f（技能树最多减 3f）。

## ⑥ 边界与失败处理
- 写盘失败：保留内存状态，提示"未保存"，不崩溃。
- 无神龛死亡：兜底用中枢岛神龛。
- 读档版本不匹配：拒绝并提示，不损坏。

## ⑦ 可测试性
- [ ] 神龛存档/读档 100% 还原状态。
- [ ] 死亡 100% 最近神龛复活且保留收集。
- [ ] 技能树效果在神龛正确应用至 S1/S2/S3。
- [ ] 写盘失败不崩溃。
