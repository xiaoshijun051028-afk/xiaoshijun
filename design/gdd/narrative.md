# GDD · 叙事系统·残响回声 (Narrative: Resonance Echoes)
> 系统编号 S7 ｜ 版本 v0.2 ｜ 依赖 S3(触发), S5(节点) ｜ 上游 概念文档 v0.2

## ① 概述与目标
以"残响回声"NPC + 共鸣节点承载世界观（Solo 无联机，Relatedness 轻量方案）。玩家在节点共鸣 → 触发失落的造物/人物残响，碎片化叙事。目标：兑现支柱 P3（精美即叙事）、SDT 关联（轻量情感连接）、美学 Narrative/Discovery。

## ② 核心机制/规则
- 残响节点：世界放置（S5），玩家按共鸣 → 节点 `RESONANCE_GLOW` 发光 + 残响播放（语音/文本/环境变化）。
- 残响内容：世界观碎片、角色弧、区域背景（对应 P3 视觉叙事）。
- 收集：残响计入"发现"进度（Explorer/Bartle）。
- 触发消耗：节点共鸣 +10 池（S3），节点 5s cd。

## ③ 状态与数据流
- 状态：echoCollected[]、nodeTriggered[]、currentEcho。
- 数据流：玩家共鸣 → S3 +10 → 触发 echo → 播放 → 标记收集 → S6 进度更新。
- 持久化：随神龛（S8）。

## ④ 与其他系统接口
- → S3：节点 +10，cd 5s。
- → S5：节点位。
- → S6：发现进度。
- → S8：存档。

## ⑤ 数值/参数初值
- 每岛 2–3 节点（同 S5）。
- 单节点触发 +10 池，cd 5s。
- 残响时长 8–20s（可跳过）。
- 总残响数：v1 ≈ 10–14。

## ⑥ 边界与失败处理
- 战斗中触发：允许，但不暂停（保持流动），回声以半透明叠加。
- 节点 cd：5s 内重复不二次触发/增益。
- 语言缺失：回退文本，不阻断。

## ⑦ 可测试性
- [ ] 所有节点可触发且 +10 池正确。
- [ ] 残响收集计入发现进度。
- [ ] 5s cd 内不重复增益。
- [ ] 战斗中触发不卡输入。
