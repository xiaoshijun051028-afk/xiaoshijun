# GDD · 世界与关卡系统 (World & Level)
> 系统编号 S5 ｜ 版本 v0.2 ｜ 依赖 S2(锚点), S3(闸门), S8(神龛位) ｜ 上游 概念文档 v0.2

## ① 概述与目标
中枢岛 + 3–4 浮岛的破碎天空王国。承载锚点（S2）、共鸣闸门（S3）、神龛（S8）、残响节点（S7）。目标：兑现支柱 P2（垂直探索）、P3（精美即叙事）、核心循环（探索→战斗→解谜→前进）。

## ② 核心机制/规则
- 岛屿结构：中枢岛（hub，含神龛与通往各岛的锚点链）+ 3–4 浮岛（含战斗区/解谜区/残响节点）。
- 锚点：每岛布置 `grapple_anchor`（S2 读取），密度满足 P2 可达比。
- 共鸣闸门：锁区域/捷径，需 S3 `GATE_COST=30` 共鸣开启。
- 神龛：唯一存档/复活点（S8），每岛 ≥1。
- 残响节点：触发 S7 叙事，共鸣 +10（S3）。
- 区域难度递进：越远岛屿敌人 telegraph 越短、密度越高（心流）。

## ③ 状态与数据流
- 状态：islandUnlocked[]、gateOpen[]、shrineActive[]、nodeTriggered[]、currentIsland。
- 数据流：玩家到达 → 解锁/开门/触发 → 持久化（S8）→ S6 地图更新。
- 不持久于单会话；进度随神龛写盘。

## ④ 与其他系统接口
- → S2：提供锚点坐标。
- → S3：闸门扣 30。
- → S8：神龛位 + 复活落点。
- → S7：残响节点位 + 触发。
- → S6：小地图/区域名。

## ⑤ 数值/参数初值
- 中枢岛 1 + 浮岛 3–4（v1 Must 取 3）。
- 锚点密度：每 1000 m³ ≥1（P2）。
- 闸门：每岛 1–2，cost 30。
- 神龛：每岛 ≥1，中枢 1。
- 残响节点：每岛 2–3。
- 难度梯度：岛 N telegraph ×(1 - 0.1·N)。

## ⑥ 边界与失败处理
- 锚点缺失导致死路：关卡校验工具扫描，发布前 0 死路。
- 闸门卡关：池不足且有唯一通路 → 提示绕路/回神龛回充。
- 越界：y 下限触发 S8 复活（同 S2）。
- 节点重复：5s cd（同 S3）。

## ⑦ 可测试性
- [ ] 每岛可达高点数/体积比 ≥ 0.6。
- [ ] 存在 ≥1 纯空中路线绕敌（每岛）。
- [ ] 0 逻辑死路（自动化可达性扫描）。
- [ ] 神龛覆盖每岛，复活落点有效。
