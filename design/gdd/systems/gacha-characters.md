## §0 设计前提（复用 gacha.md 裁决）

- 五维：`hp / attack / defense / move_speed / resonance_affinity`，基准 = 100。
- 数值公式（整数，先乘后除）：`final = base × eff_mult_milli(稀有度, 权重) × roll_milli / 1e6`。
- `hp` 与 `move_speed` **不 roll**（roll 恒 1000）；`attack / defense / affinity` 抽时独立 roll 一次 `[950,1050]` 步长 5，永久锁定。
- 下文 **每稀有度数值表采用 roll=1000 的基准档**（即 `base × eff_mult` 向下取整），代表该稀有度的"中位强度"；真实抽出会因 ±5% 浮动。
- 窗口帧数（取消 8f / 完美格 / 无敌帧）**任何角色不得修改**（gacha.md §6.1 红线）。
- 共鸣亲和只影响**终结技产出**，不影响共鸣池收入（ADR-002）。
- 技能效果全部基于现有战斗动词（斩 slash / 闪 dash / 跃 leap / 格 parry / 共鸣 resonate），**不引入新引擎系统**。

### 维度权重（来自 gacha.md §3.3）

| 维度 | 权重 | N | R | SR | SSR 实际乘区 |
|---|---|---|---|---|---|

## §2 技能设计（每名角色：1 主动 + 1 被动）

设计原则：技能是**已有战斗动词的编排 + 数值调制**，不新增引擎系统；被动不破坏 P1/P2/窗口红线；谐律系技能只动终结技"产出"。

### 锋刃 BLADE（高攻脆皮，奖励零失误）
**1.1 灰烬学徒 `ash_acolyte`**
- 主动 **「余烬斩」**：蓄力 0.4s 后释放一次重斩（slash 变体），命中后获得 6s 自增益 `attack_power ×1.15`（叠加在现有 attack 标量上，到期自动消失）。CD 8s。
- 被动 **「灰烬余温」**：完美格挡（perfect parry）成功后，下一次斩击伤害 +25%（一次性标记，斩出即消耗）。
- lore：坠落王国的见习执剑人，剑柄余温尚存。

**1.7 断空剑主 `voidblade_lord`**
- 主动 **「断空」**：瞬步突进（dash）穿越至目标背后并接大斩，对路径与终点敌人造成伤害，可取消普通连段后摇进入。CD 6s。
- 被动 **「虚空回响」**：当连段数 ≥4 时，终结技（共鸣）伤害额外 +20%（在 affinity 加成之上叠加）。
- lore：斩开虚空者，剑光所至再无间距。

### 磐盾 BULWARK（高容错，守护系）
**1.2 誓锁守卫 `oath_guard`**
- 主动 **「誓锁壁垒」**：展开护盾 4s，期间受到伤害 ×0.5（在 defense 公式之后再乘减伤）。CD 12s。
- 被动 **「不屈」**：hp 低于 30% 时 defense 标量 +20%（常驻直到回复过阈值）。
- lore：以誓约为锁，以身化壁。

**1.5 磐心卫士 `bulwark_heart`**
- 主动 **「磐心脉冲」**：以自身为中心释放一次范围震退（knockback）+ 固定伤害，打断附近敌人 telegraph。CD 10s。
- 被动 **「守护共鸣」**：完美格挡成功时回复 hp +8（不超 max_hp）。
- lore：心跳如磐石，护友于喧嚣。

### 风追 WINDCHASER（迅捷，解锁空中路线）
**1.3 迅羽游侠 `swift_ranger`**
- 主动 **「迅羽突袭」**：高速冲刺（dash）穿越敌人并留下伤害残影，残影 1.5s 内对触碰敌人持续造成伤害。CD 7s。
- 被动 **「疾风之翼」**：常驻 `move_speed` 标量 +8%（叠加在角色数值上，影响关卡位移）。
- lore：风托起每一根羽毛，亦托起每一次逃离。

**1.4 疾风回响者 `gale_echo`**
- 主动 **「回响疾风」**：强化二段跳 + 空中 dash 不消耗落地计数，2.5s 内可无限空中 dash（平台跳跃特化）。CD 9s。
- 被动 **「风追节拍」**：连续 dash 不中断连段计数（combo 不因闪避归零）。
- lore：风过处，是同一个动作的千万次回声。

### 谐律 RESONANT（共鸣特化，终结技强化）
**1.6 谐律主祭 `resonant_hierophant`**
- 主动 **「谐律圣咏」**：立即向共鸣池注入 +30（开门/终结技资源），但此后 10s 内自然增长暂停。CD 15s。**不改变成本常量（GATE_COST=30/FINISHER_COST=40）。**
- 被动 **「主祭恩泽」**：终结技伤害额外 +30%（在 affinity 加成之上，不改变成本，只改产出 → 守 P4 互斥张力）。
- lore：以歌声校准世界的频率。

**1.8 共鸣歌者 `resonant_singer`**
- 主动 **「共鸣歌」**：对周围敌人施加易伤（受击伤害 +20%，持续 5s）。
- 被动 **「和声」**：击杀敌人时共鸣池 +5（额外收入，独立于 ADR-002 的击杀+15 常量；属"击杀奖励"语义，不替代常量收入）。
- lore：她唱，世界便低声应和。

## §3 与战斗系统的接入约束（工程交付清单）

| 接入点 | 说明 |
|---|---|
| `PlayerCombat.apply_character(stats)` | 注入五维（已实现，gacha.md §6.1）。技能在注入后由 `SkillComponent` 读取 `archetype`/角色 id 决定激活哪套。 |
| 主动技 CD | 各角色独立 CD 计时器，HUD 不新增元素（守认知过载）。 |
| 被动挂载 | `PlayerCombat` 初始化时按 `active_character_id` 注册被动回调（如完美格挡→`守护共鸣`回血）。 |
| 攻击力尚未接入伤害公式 | gacha.md 已记 deferred：`attack_power` 字段已注入但**暂未**进入命中结算（避免动摇 S1 核心）。**本文件不对此做改动**，留专项。 |
