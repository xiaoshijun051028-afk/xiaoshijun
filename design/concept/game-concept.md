# 游戏概念文档 · 星陨之境 (Aetherfall)

> 版本：v0.2（Phase 1 概念孵化 · 色彩对齐美术圣经修订）
> 引擎：Godot 4 (3D) ｜ 平台：PC / Steam ｜ 评审强度：Solo ｜ 类型：爽快动作冒险（含战斗）
> 美术目标：3D 精美 / stylized PBR
> 概念种子：坠落的浮空群岛世界"星陨之境"，玩家持"星刃"在破碎天空王国中战斗、探索、解谜，对抗混沌侵蚀的机械造物。
> 核心动词方向：斩 / 闪 / 荡 / 跃 / 共鸣

---

## 1. 游戏支柱（Game Pillars）

四条支柱，每条可落地、可验证，且互相不打架。

**P1 · 流动即正义（Flow Combat）**
一句话：斩 / 闪 / 荡 / 跃 / 格之间必须存在 ≤8 帧的取消窗口，让连段与位移无缝衔接。
为什么：本作核心爽点目标是"爽快"，输入链一旦断裂，沉浸感崩塌速度远超任何画面瑕疵。
验证：原型阶段以"连续技中断率"与"平均连段长度"量化；中断率 < 5% 视为达标。

**P2 · 垂直即世界（Verticality）**
一句话：浮空群岛的主玩法场是空中垂直空间，通过荡 / 跃 / 闪而非步行推进。
为什么：把"浮空"从背景板变成机制，与平地开放世界拉开差异，并天然制造探索惊喜。
验证：单张岛屿"可达高点数 / 总可探索体积比" ≥ 0.6；且存在至少 1 条"纯空中路线"可绕过地面敌人。

**P3 · 精美即叙事（Beauty as Narrative）**
一句话：stylized PBR + 体积光 + 强氛围承担世界观传达，玩家在文字之前先"读"到故事。
为什么：Solo 范围撑不起重型过场，美术必须替叙事承重。
验证：关键区域无任何文本提示时，玩家凭视觉推断"这里曾发生什么"的比例测试 ≥ 70%。

**P4 · 共鸣统一（Resonance Unifies）**
一句话："共鸣"是同时驱动解谜闸门与战斗终结技的元技能，二者共享同一能量池。
为什么：用单一动词统合探索与战斗两支柱，避免内容膨胀与玩家在两个系统间割裂。
验证（防主导策略）：共鸣池同时承担"开门"与"终结技"且互斥消耗——不存在"只点战斗不点解谜"的主导策略。

## 2. MDA 框架分析

| 层 | 内容 |
|---|---|
| **Mechanics（机制）** | ① 5+1 核心动词状态机（斩 / 闪 / 荡 / 跃 / 格 / 共鸣）含取消窗口；② 星刃共鸣能量池（resonance gauge）；③ 混沌侵蚀造物的"可判读 AI"（预警色 + 招式 telegraph）；④ 轻重力浮空物理与锚点系统；⑤ 共鸣锁环境谜题节点；⑥ 神龛存档 / 复活。 |
| **Dynamics（动态）** | ① 闪取消让斩序列保持压制，涌现"流动战斗"；② 垂直探索涌现捷径与"绕怪空中路线"；③ 共鸣池投资权衡：开门 vs 终结技互斥；④ 玩家自发发现"天空捷径"跳过战斗。 |
| **Aesthetics（美学 / LeBlanc 8）** | **Sensation**（风格化 PBR 美、体积光、命中反馈）、**Fantasy**（持星刃、修复坠落天空王国）、**Discovery**（浮岛 / 碎片叙事）、**Challenge**（技巧向精确闪避 / 格挡）、**Narrative**（悲壮坠落王国 + 角色弧）、**Expression**（共鸣配装差异化，Should 级）；*Fellowship* 与 *Submission* 非目标（Solo，明确不做）。 |

> 美学取舍：Solo 评审下，Fellowship 与 Submission 主动放弃，资源集中投入 Sensation / Challenge / Discovery 三项。

## 3. 核心动词表（动词优先法）

| 动词 | 玩法意图 | 爽点 |
|---|---|---|
| **斩 Slash** | 主伤害手段，轻重击混合，可在收招中取消接闪。 | 命中顿帧（hit-stop）+ 轻微震屏，破碎感"崩"反馈。 |
| **闪 Dash** | 无敌帧（i-frame）位移、调整站位、取消斩收招。 | 完美闪触发极短缓时，能"穿"过敌人身体。 |
| **荡 Grapple** | 拉向锚点 / 空中单位、拉近距、垂直移动。 | 动量守恒的摆荡，掠过裂隙的失重感。 |
| **跃 Leap** | 垂直起跳、平台跳跃、跨越断崖。 | 滞空悬停 + 落地冲击波（landing shockwave）。 |
| **共鸣 Resonate** | 引导星刃：解锁闸门 / 强化终结技，共享能量池。 | 全屏谐波脉冲，世界随共鸣"回应"你。 |
| **格 Parry** | 格挡 telegraphed 攻击，破防开硬直窗口。 | 完美格"叮" + 慢动作，防守即时转进攻。 |

> 防认知过载：6 个动词共用一套"取消 / 预警"语言（统一色码与音效），不引入独立资源条，避免 HUD 过载。

## 4. 玩家心理学映射

**自我决定论（SDT）**
- **自主 Autonomy**：开放天空路线 + 多解法（潜行绕怪 / 强攻）+ 共鸣配装自由选择。
- **胜任 Competence**：紧凑取消窗口奖励精通；预警 telegraph 让玩家"觉得自己聪明"而非靠运气。
- **关联 Relatedness**：Solo 下不做联机，改为"残响回声"叙事 NPC 与可共鸣的失落造物，提供轻量但真实的情感连接。

**心流（Flow / Csikszentmihalyi）**
- 挑战—技能平衡：敌人 telegraph 随区域递进，难度靠"读招精度"而非数值碾压；无等级碾压式 gating。
- 提供难度选项 + NG+（Should）以守住高 / 低技能玩家的心流带。

**Bartle 玩家类型覆盖策略**
- **Achiever（成就型）**：战斗评级、可选天空路线全收集。
- **Explorer（探索型）**：隐藏浮岛、碎片叙事、垂直捷径。
- **Socializer（社交型）**：Solo 弱覆盖——靠 Steam 成就 / 截图分享 + 残响叙事补足（不做联机核心）。
- **Killer（杀手型）**：战斗精通排行（Could：Steam 排行榜）、Boss 速杀挑战。

## 5. 范围分层（MoSCoW · v1 边界）

**Must（v1 必做）**
- 核心 5+1 动词 + 取消窗口原型；神龛存档 / 复活。
- 1 中枢岛 + 3–4 张可探索浮岛；轻重力荡 / 跃垂直移动。
- 3 种敌人原型 + 1 个区域 Boss；预警 telegraph 战斗。
- 共鸣锁谜题闸门（解谜 ↔ 战斗共用能量池）。
- 基础 HUD（血量 / 共鸣池 / 目标）、PC 键鼠 + 手柄、Steam 可运行构建。

**Should（应做）**
- 共鸣配装技能树（Expression）；2 个 Boss；可选天空捷径系统；残响回声 NPC；拍照模式。

**Could（可做）**
- NG+；Steam 成就 / 排行榜；多结局；动态天气；本地"回声"陪战。

**Won't（v1 不做）**
- 联机合作核心；移动端移植；分支对话重叙事；crafting / 经济系统；无尽模式。

## 6. 核心循环（Core Loop）

**宏观 Core Loop（区域级）**
探索浮岛 → 遭遇混沌造物 → 流动战斗（斩 / 闪 / 格）→ 共鸣解锁闸门 / 谜题 → 获得碎片叙事或升级 → 通过荡 / 跃前往下一张岛 → 区域末端 Boss。循环直至"修复天空王国"主线推进。

**单次会话循环（Session Loop）**
启动 → 在神龛读档 → 选择目标（主线 / 探索 / 收集）→ 20–40 分钟"移动 + 战斗 + 谜题"单元 → 抵达里程碑 / Boss → 神龛存档 →（可选）自由探索或调整共鸣配装 → 退出。单会话目标清晰、可随时安全退出，契合 PC 玩家碎片化时间。

## 7. 视觉锚点（供美术圣经 / Art Bible）

**① 氛围 Atmosphere**
"云端之上"的宁静与混沌侵蚀区的压迫形成强对比。体积光（god-rays）自云海裂隙穿刺而下，空气中悬浮尘埃微粒（dust motes）随玩家移动轻微扰动；进入被侵蚀区时光线收窄、雾变冷、出现缓慢飘浮的锈屑。整体追求"明快但克制"的电影感，而非一味高亮。

**② 色彩 Color**
高饱和但和谐的三段式色板：① 天空域——青绿（teal）+ 琥珀（amber）主调，象征希望；② 植被 / 魔法——青绿（teal）+ 暖金（amber）+ 珊瑚（coral，暖）点缀，制造东方奇幻的华丽感；③ 混沌造物——枪铁灰底 + 混沌品红（#A62C6B）脉冲作"危险可读"色码（品红锁敌人 / 混沌专属威胁色）。统一用略带暖灰的中性背景托底，避免荧光过载。

**③ 材质 Material**
stylized PBR：有机体（植被 / 角色）用轻微次表面散射（SSS）呈现"果冻感"生命感；造物用干净锐利的金属度（metalness）高反差，silhouette 极简可读；遗迹石构用哑光粗糙（matte rough）表现岁月。所有"共鸣"相关物体加自发光（emissive）描边，作为交互提示的统一视觉语言。

**参考方向（具体可执行）**：《原神》开放天空的 stylized 体量、《对马岛之魂》的色彩分级与氛围、《地平线》机械造物 × 自然的造型语言、《二之国》东方 × 日式绘本的笔触质感。
